## Setup and Libraries
For this season we used PROS and Lemlib.

**PROS:**
PROS (Purdue Robotics Operating System) is an open-source C/C++ development environment for VEX V5 robots, built by Purdue University students as a more powerful alternative to VEXcode. It runs in VS Code, gives you full control over the robot's hardware, and supports multitasking so you can run multiple operations at the same time. Most serious competitive teams use it because of how much more flexibility it gives you compared to VEXcode.

**Lemlib:**
LemLib is an open-source C++ library built on top of PROS that makes advanced autonomous programming way easier for VEX V5 teams. It handles the hard stuff like odom, path following, and PID tuning out of the box, so you don't have to build all that from scratch with PROS.

As a first year prog, this made my life so much easier.

## Solo AWP
The Solo AWP is a route that aims to achive the Autonomous Win Point by yourself without depending on an alicence. For eariler season events, the requirements for the AWP was as follows:
- 7 blocks scored
- 3 blocks of the aliences color taken from loaders
- 3 goals with at least one block scored in each
However, for world qualifying events, such as states, the requirement for the autonomous win point were slightly harder.
- 10 blocks scored
- 3 blocks of aliences' color taken from BOTH loaders
- 3 goals with at least 2 blocks scored

Dispite earlier season being easier, we still aimed for the world-quallifying requirements, just to be safe. This was our route.
![GIF of SOLO AWP ROUTE](https://github.com/K-man1/states_bot_prog/blob/main/soloAWP.gif)

This route, which goes long goal -> long goal -> middle goal is an evolution of an easier (and shorter) route that went long -> middle -> long. We decided to change to the route as it allows us to descore any blocks from the opposing team in the middle goal, and make sure none of our's gets descored either.

## 4 Ball
The 4 ball route is an elimation round auto where you get 3 blocks from the loader, and score 4 (preload included) into the long goal and then using the wing to push the blocks into the control zone. It is a simplyified version of the 7 ball, which also intake 3 trio blocks.
![4 BALL GIF](https://github.com/K-man1/states_bot_prog/blob/main/4ball.gif)

We deicided to do a 4 ball as it was easier to code (because we were doing it during comp) and would wing the control zone as it is faster than oppenent 7 ball autos.
